Compass 

A course recommendation web app that helps users find the most suitable online courses based on their preferences.

Live Demo:  
https://jasoncho0322.github.io/compass-course-recommender/

Features
- Topic-based course search
- Score-based recommendation system
- Personalized recommendation reasons
- Bilingual UI (English / Korean)
- Mobile responsive design
- Fast client-side filtering (no backend)

How It Works
Users input:
- Topic
- Level
- Goal
- Budget
- Language

The system:
1. Filters courses by topic
2. Assigns scores based on matching conditions
3. Sorts by score
4. Displays top recommendations with explanations

Tech Stack
- HTML
- CSS
- JavaScript
- GitHub Pages (deployment)
  

Why I Built This
I wanted to create a simple but practical tool that helps people choose online courses more effectively.
Instead of just listing courses, Compass focuses on **personalized recommendations with clear reasoning**, improving user decision-making.
